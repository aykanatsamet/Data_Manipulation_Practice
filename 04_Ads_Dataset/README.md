## 📓 Notebook Descriptions

### 01_data_understanding_eda.ipynb
Initial exploration of the dataset including:
- Dataset structure and data types
- Descriptive statistics
- Identification of potential data quality issues

### 02_data_cleaning_eda.ipynb
Exploratory data analysis and data cleaning:
- Missing value analysis
- Univariate and bivariate analysis
- Correlation analysis
- Key behavioral insights

### 03_feature_engineering.ipynb
Preparation of data for modeling:
- Removal of non-informative features
- Encoding categorical variables
- Feature scaling
- Creation of a processed dataset for modeling

### 04_model_training.ipynb
Model development phase:
- Train-test split
- Logistic Regression as a baseline model
- Random Forest as an advanced ensemble model
- Initial model comparison

### 05_model_evaluation.ipynb
Comprehensive model evaluation:
- Confusion matrix analysis
- Precision, Recall, and F1-score
- ROC-AUC analysis
- Model comparison and interpretation

## 📈 Key Findings
- Age and estimated salary are significant predictors of advertisement purchase behavior.
- Random Forest outperforms Logistic Regression in terms of ROC-AUC.
- Logistic Regression provides strong interpretability and serves as a reliable baseline model.

---

## ⚠️ Limitations
- The dataset contains a limited number of features.
- Behavioral and temporal user data are not included.
- Results may not generalize to all advertisement platforms.
