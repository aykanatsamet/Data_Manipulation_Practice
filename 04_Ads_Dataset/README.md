# Advertisement Purchase Prediction  
### Data Science & Machine Learning Project

## Overview
This project focuses on analyzing user demographic data related to online advertisements
and predicting whether a user will make a purchase after being exposed to an advertisement.

The project is designed as a complete data science case study, following a structured
workflow from data exploration to model evaluation. It aims to demonstrate practical
data analysis skills, machine learning knowledge, and analytical thinking.

---

## Problem Statement
Online advertisement platforms aim to understand which users are more likely to convert
after viewing an advertisement. By analyzing user demographics such as age, gender, and
estimated income, this project seeks to build predictive models that can estimate
purchase likelihood.

The problem is formulated as a **binary classification task**, where the target variable
indicates whether a purchase occurred.

---

## Dataset
The dataset consists of anonymized user-level information commonly used in
advertisement analytics and machine learning demonstrations.

**Main attributes:**
- User demographics (age, gender)
- Economic indicator (estimated salary)
- Purchase outcome (binary target variable)

The dataset is intentionally simple to allow clear interpretation of results
and to focus on methodological correctness.

---

## Methodology
The project follows a standard data science pipeline:

1. Data understanding and exploratory analysis  
2. Data cleaning and preprocessing  
3. Feature engineering  
4. Machine learning model training  
5. Model evaluation and interpretation  

Each step is implemented with reproducibility and clarity in mind.

---

## Technologies Used

---

## Key Insights
- User age and estimated salary show a strong relationship with purchase behavior.
- Machine learning models can effectively predict advertisement conversion likelihood.
- Model interpretability and predictive performance must be balanced depending on use case.

---

## Limitations
- The dataset contains a limited number of features.
- Behavioral and contextual advertisement data are not included.
- Results may not generalize to real-world advertising systems without additional data.

---

## Future Improvements
